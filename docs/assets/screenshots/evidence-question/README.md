# 공고 상세 근거 답변 실제 사용 화면

메인 README의 **8.2 공고 상세의 근거 기반 답변(RAG)**에서 사용하는 실제 웹 화면입니다.

- 캡처일: 2026-10-15
- 화면: 로컬 React 웹 `/app/support-programs/detail`의 공고 상세와 원문 질문 패널
- 계정: 개발용 관리자 시드 계정. 계정 정보가 나오지 않도록 사이드바를 접었습니다.
- 공고: 기업마당 `PBLN_000000000122863`, `[경북] 2026년 제조업AI융합기반조성사업 경북AX랩 활용기업 모집 공고`
- 질문: `지원 대상과 신청 방법을 알려 주세요.`
- 실행: 공고 상세에서 원문에 질문하기 → 질문 입력 → 질문 보내기 1회 → 답변 확인 → 근거 원문 펼치기를 순서대로 진행했습니다. 답변은 보낸 뒤 약 5초 만에 표시되었습니다.
- AI: 현재 저장소의 AI 코드로 답변을 새로 생성했습니다. 근거는 저장된 공식 HTML 원문과 기존 Qdrant 색인을 사용했습니다.
- 데이터: 공고 상태·마감일·문의처는 캡처 당시 화면의 표시값입니다. 문의처는 공고 원문에 공개된 기관 연락처입니다. 이 1회 답변을 답변 품질 전체의 검증으로 일반화하지 않습니다.
- 편집: 폭 1100px 화면을 2배율로 캡처한 뒤 기존 README 사진과 같은 **800×882 JPEG**로 줄였습니다. ①은 화면 전체, ②~④는 오른쪽 질문 패널 주변만 잘랐습니다. 응답 대체·화면 문구 수정·이미지 합성은 하지 않았습니다.
