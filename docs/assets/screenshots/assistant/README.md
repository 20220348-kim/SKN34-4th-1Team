# GovBiz 도우미 실제 사용 화면

메인 README의 **8.4 GovBiz 도우미**에서 사용하는 실제 웹 화면입니다.

- 캡처일: 2026-10-15
- 화면: 로컬 React 웹 공고 상세(`PBLN_000000000122863`) 위에 연 도우미 패널
- 계정: 개발용 관리자 시드 계정. 계정 정보가 나오지 않도록 사이드바를 접었습니다.
- 실행
  - ① 도우미를 열었습니다.
  - ② 자유 질문 `신청 문서 초안은 어떻게 만들어요?`를 1회 보냈습니다. 공고 상세에서 연 질문이라 AI가 공고 원문 확인이 필요한 질문으로 분류했고, 원문 질문 열기로 안내했습니다.
  - ③ `관심 공고 마감 확인` 버튼을 눌렀습니다.
  - ④ `중복 검토·신청 문서` 주제에서 `신청 문서는 어떻게 만드나요?` 도움말을 열었습니다.
- AI: ②만 현재 저장소의 AI 코드로 새로 분류·응답했습니다. 답변은 보낸 뒤 약 5초 만에 표시되었습니다. ③은 관심 공고 API 조회, ④는 저장된 도움말이라 모델을 호출하지 않습니다. 같은 질문도 화면 문맥에 따라 분류가 달라질 수 있습니다.
- 데이터: ③의 관심 공고 수·마감일은 로컬 관리자 계정의 캡처 당시 값입니다. 패널 왼쪽에 일부 보이는 연락처는 공고 원문에 공개된 기관 문의처입니다.
- 편집: 폭 1100px 화면을 2배율로 캡처한 뒤 오른쪽 아래 도우미 패널 주변을 잘라 **800×882 JPEG**로 줄였습니다. 응답 대체·화면 문구 수정·이미지 합성은 하지 않았습니다.
