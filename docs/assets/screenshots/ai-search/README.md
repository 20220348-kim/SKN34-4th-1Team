# AI 대화 검색 실제 사용 화면

메인 README의 **8.1 AI 대화 검색**에서 사용하는 실제 웹 화면입니다.

- 캡처일: 2026-10-10
- 화면: 로컬 React 웹 `/app/chat`
- 질문: `서울에 있는 AI 창업기업입니다. 사업화 지원사업을 찾아주세요.`
- 실행: 새 검색을 시작해 질문 전송 → 조건 제안 → 확인 버튼 → 추천 결과 → 원문 근거 펼치기를 순서대로 진행했습니다.
- AI: 현재 저장소의 AI 코드를 실행해 조건 해석과 추천을 `gpt-6-luna`로 새로 생성하고, 질문 임베딩과 기존 Elasticsearch·Qdrant 색인으로 후보를 검색했습니다.
- 결과: 후보 20건을 평가해 확인 필요 공고 3건을 반환했습니다. 결과 화면은 첫 번째 공고를 보여 줍니다.
- 데이터: 기존 로컬 공고·색인을 사용했습니다. 공고 상태·마감일·관련도는 캡처 당시 화면의 표시값이며, 최신 공고 수집이나 추천 품질 전체를 검증한 기록은 아닙니다.
- 편집: 브라우저 화면을 JPEG로 저장했습니다. 응답 대체·화면 문구 수정·이미지 합성은 하지 않았습니다. 계정 정보가 나오지 않도록 사이드바를 접었습니다.
