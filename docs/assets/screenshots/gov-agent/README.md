# 관리자 Gov 에이전트 실제 사용 화면

메인 README의 **8.5 관리자 Gov 에이전트**에서 사용하는 실제 웹 화면입니다.

- 캡처일: 2026-10-15
- 화면: 로컬 React 웹 `/app/chat`의 Gov 에이전트
- 계정: 개발용 관리자 시드 계정. 계정 정보가 나오지 않도록 사이드바를 접었습니다.
- 대화: 2026-10-14에 실제로 실행해 저장된 관리자 대화 두 개를 다시 열었습니다.
  - ①은 `서울 AI 창업지원 사업 찾아줘` 요청에 대한 조건 제안이 확인 전 상태로 남은 대화입니다.
  - ②~⑥은 같은 요청으로 검색한 뒤 작업 버튼으로 신청 문서·중복 검토·파트너 카드를 만든 대화입니다.
- 실행: 저장된 대화를 열고 스크롤만 했습니다. ③은 대화 맨 아래 입력창 위에 마지막으로 고른 공고가 표시된 모습이라 ②·④의 공고와 다릅니다. ⑥은 중복 검토 카드의 `중복 검토 화면에서 시작하기`로 연 대화 위 시트이며, 저장하지 않고 닫았습니다.
- AI: 대화를 다시 여는 과정에서는 모델 호출·검색·분석을 다시 실행하지 않았습니다. 화면의 추천 결과와 카드는 저장된 대화 기록입니다.
- 데이터: 공고 상태·마감일·관련도는 저장 당시 결과이며, 화면 위쪽의 안내처럼 현재 원문에서 다시 확인해야 합니다.
- 편집: 폭 1100px 화면을 2배율로 캡처한 뒤 대화 영역을 잘라 **800×882 JPEG**로 줄였습니다. ⑥은 화면 전체입니다. 응답 대체·화면 문구 수정·이미지 합성은 하지 않았습니다.
