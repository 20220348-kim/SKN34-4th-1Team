# LLMOps 평가 실행 경로 선택 화면

메인 README의 **9.3 세 가지 평가 방식 → 화면에서 세 가지 실행 경로 선택하기**에서 사용하는 실제 웹 화면입니다.

- 캡처일: 2026-10-10
- 화면: 로컬 React 웹 `/ops/evaluations/new`, 기존 관리자 로그인 세션
- 소스 기준: `00`~`02`는 `4aea10e`, `03`은 평가용 벡터 재사용을 반영한 작업본의 `frontend/web/src/presentation/features/ops/OpsApp.tsx`
- 조작: 실행 방식과 평가 자료의 선택값만 바꾸었습니다. 평가 실행·예산 예약·모델 API 호출·검토 저장은 하지 않았습니다.
- 실행 설정: 캡처 당시 새 모델 평가는 비활성화 상태였습니다. 사진은 실행 경로의 선택 방법을 보여 주며, 실행 가능 상태나 완료 결과를 입증하지 않습니다.
- 편집: 실제 브라우저 스크린샷에서 공통 진입 화면의 메뉴·안내 영역과 각 방식의 제목·범위 안내·실행 방식·평가 자료 영역을 잘라 JPEG로 저장했습니다. 계정 정보는 제외했습니다. UI 문구 수정·응답 대체·이미지 합성은 하지 않았습니다.
- 배치: 공통 진입 화면 1컷과 세 가지 실행 경로 선택 화면 3컷을 2×2로 배치했습니다. 공통 진입 화면은 동일한 촬영 원본에서 잘랐으며, 네 가지 평가 방식이나 네 단계의 연속 실행을 뜻하지 않습니다.
- 선택값: 최초 촬영 후 저장 응답 재평가·가상 평가 자료 선택으로 복원했습니다. `03` 갱신 후에는 RAG 자료와 벡터 준비 계획을 확인할 수 있도록 선택 상태를 유지했습니다.

실행 방식 메뉴는 두 옵션입니다. `새 응답 생성`일 때 평가 자료의 범위가
`fixed-answer-context-only`이면 고정 근거 답변을, `source-chunks-retrieval-answer`이면 RAG를 실행합니다.
저장 응답 재평가는 해당 자료의 저장 캡처를 사용합니다.
