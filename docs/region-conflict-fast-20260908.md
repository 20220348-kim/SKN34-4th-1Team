# 지역 충돌 판정 보완과 Fast 상시 설정 — 2026-09-08

## 변경 내용

사용자 승인에 따라 로컬 `.env`와 공유 `.env.example`에
`OPENAI_RANKING_SERVICE_TIER=priority`를 명시했습니다. Sol/low 랭킹에만 Fast를 요청하며,
현재 일반 처리 대비 토큰 단가는 2배입니다. 대화 조건 해석·RAG·임베딩 설정은 그대로입니다.
환경변수를 생략한 코드·Compose 기본값은 `default`로 유지합니다.
[OpenAI 공식 Fast 안내](https://developers.openai.com/api/docs/guides/fast-mode)

Fast는 처리 등급 변경이며 정확도 수정 자체가 아닙니다. 지역 오류는 별도로 프롬프트와 내부
`regionAssessment` schema의 판단 전제를 일치시켜 보완했습니다. 후보 수·관련도 배점·출력 계약·
45초 모델/50초 Agent 제한을 바꾸지 않았으며 추가 Agent·LLM 호출·도시별 필터·fallback은 없습니다.

## 오류 원인과 수정 범위

[이전 실제 검색](../evaluation/support-program-search/runs/search-latency-20260908-v1/search/capture.json)에서
서울 SW 기업에 안산 관내 기업 대상 공고 `BIZINFO:PBLN_000000000125900`이 추천됐습니다.
지역 조건과 본문이 전달됐고 절단되지도 않았지만, 모델은 추가 안산 사업장 여부가 미확인이라는
이유로 지역 충돌을 `UNKNOWN`으로 남겼습니다. 기존 내부 schema의 '상위 지역만 알고 공고가 하위
지역이면 UNKNOWN' 설명에는 **하위 지역이 확인된 회사 지역 안에 있어야 한다는 전제**가 없었습니다.

- 서울 회사 / 서울 서초구 한정: 서초구 소재 여부가 없으므로 `UNKNOWN`.
- 서울 회사 / 경기 안산시 관내 기업: 서로 다른 지역이므로 `INCOMPATIBLE`.
- 경기 회사 / 경기 안산시 관내 기업: 안산시 소재 여부가 없으므로 `UNKNOWN`.
- 원문이 이전 예정·별도 사업장 등 다른 신청 경로를 실제 허용하면 그 경로를 따로 판단합니다.
  이미 충족한 경로가 있으면 다른 경로의 미확인으로 `MATCH`를 낮추지 않습니다.
- 원문에 없는 지점·이전 경로는 만들어내지 않습니다. 개인 거주지는 회사 소재지와 구분합니다.

처음 보완한 지침은 합성 54개 중 별도 사업장 사례 1개를 잘못 제외했습니다. 이를 숨기지 않고
v1의 **54/54 → 53/54** 실패를 보존했습니다. 후속 v2는 `또는`뿐 아니라 `중 하나`·`하나 이상`의
대안을 같은 3값 규칙으로 구분합니다. 원문이 허용한 사업장의 유무를 모르는 것은 그 사업장이 없다는
증거가 아니며, 사업장 종류가 없는 회사 지역을 본점·공장의 개별 주소로 일반화하지 않습니다.

v2는 합성 54/54였지만 공개 대구 여성창업 공고를 회사 서울 주소로 제외했습니다. 최종 지침은
**지역 비교 전에 제한 대상이 일반 회사인지, 특정 종류의 사업장인지, 개인인지 먼저 식별**하도록
순서를 명시했습니다. 주소의 주체가 다르면 같은 주소로 대입하지 않습니다.

`관내 기업`이라는 지원 대상 문구에는 반드시 '만'이 붙어야 하는 것이 아닙니다. 반면 행사 장소나
기관 주소·태그만으로 소재지 제한을 만들지 않으며, 잘린 본문은 기존처럼 `UNKNOWN`입니다.
이는 모델 판단 지침의 보완이지, 서버가 모든 행정구역과 신청 자격을 독립적으로 증명하는 구현은 아닙니다.

## 고정 검증과 해석 기준

[실행 자료](../evaluation/support-program-search/runs/region-conflict-20260908-v1/README.md)에 입력·변경 전
프롬프트/Agent·전체 후보 판정·원문 근거·최종 추천·설정/소스 해시·API 사용량을 보관합니다.

- 합성 공고 18개 × 회사 소재지 3개 = 지역 판정 54개를 변경 전후 같은 Sol/low/Fast로 비교합니다.
- 공개 공고 20개에 대한 서울 SW 지원금 질문을 수정 후 2회 반복합니다.
- 안산 한정 `125900`은 제외하고, 대구 소재 **또는 이전** 허용 `124940`의 지역은 `UNKNOWN`으로
  보존하는지 구분합니다. 두 공고를 모두 타지역이라는 이유로 제외하는 검사가 아닙니다.
- 실제 Core 검색은 동일한 서울 SW 지원금 조건으로 1회만 확인합니다.
- 최초 승인 예산은 직접 랭킹 8회 + 실제 검색 임베딩 1회·랭킹 1회였습니다. 회귀 발견 후 사용자가
  동일한 5회 재검사를 추가 승인해 총 한도는 **15회**가 됐습니다. 자동 재시도는 없습니다.

기대값은 실행 전에 AI가 작성·독립 검수한 개발용 사례입니다. 사람 검증 정답이나 heldout 평가가 아닙니다.
회사 지역만으로 본점과 공장의 위치를 각각 특정할 수 없다는 가정도 합성 기대값에 명시했습니다.
변경 전 합성 검사도 54/54로 통과했으므로 이를 정확도 상승 수치로 제시하지 않습니다. 실제 오류가 있었던
공개 공고의 재검사와 기존 예외의 회귀 확인을 별도로 읽어야 합니다.

최종 확인 검색은 **HTTP 200, 36.517초**였습니다. 임베딩 4.749초, 전체 의미 검색 5.082초,
후보 20개 모델 랭킹 30.135초였으며 두 캐시 모두 miss였습니다. 대화 조건 해석이 끝난 뒤의 확인
검색 API 시간으로, 대화 전체 시간이나 운영 p95가 아닙니다. 이전 일반 처리 42.467초와는 한 번씩의
관측이므로 개선율이나 시간 초과 완전 해결을 보장하지 않습니다.

최종 결과는 `125611`(모두의 창업), `125748`(대구 여성창업), `126187`(부산 본사 조건)입니다.
여성창업의 개인 주소는 회사 서울 주소로 알 수 없어 지역 `UNKNOWN`으로 보존됐습니다. 본사 조건도
현재 입력이 본사 주소인지 명시하지 않아 `UNKNOWN`입니다. **현재 정책은 UNKNOWN도 관련도순 추천에
포함**하므로, 다른 지역 태그가 있는 공고가 전부 사라지는 변경은 아닙니다. 실제 신청 가능을 보장하지 않으며
해당 개인·본사 소재지를 추가 확인해야 합니다. 본사 주소를 회사 region과 동일시할지는 별도 제품 계약입니다.

최종 보완 후 전체 합성 모델 검사를 다시 하지 않았고, 제주 개인/사업자 대안의 반복 변동도 최종 전체
후보 응답으로 재검증하지 않았습니다. 합성 54/54를 최종 소스의 전수 정확도로 표현하지 않습니다.
직접 랭킹 **13회 모두 priority** 응답을 확인했고 실제 검색 임베딩·랭킹 각 1회를 더해 승인된 **15/15회**로
종료했습니다. 실패·부분 통과·중간 소스 스냅샷을 모두 공유하며 더 호출하지 않았습니다.
