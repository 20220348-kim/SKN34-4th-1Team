3. 두 원본 실행의 현재 미리보기·증거 해시를 확인하고, 검토 사유와 함께 과거 사용량을 한 번씩 반영한다.

5. 고정 근거 live만 임시 활성화하고 실행기·자료·접수 준비를 확인한다. RAG와 정기 실행은 활성화하지 않는다.

7. 성공·실패·취소에 관계없이 상태·장부를 확인하고 live를 다시 비활성화한다.
   사용량 미확정은 예약을 유지하며, 실패를 이유로 모델을 자동 재호출하지 않는다.

   실행 완료를 품질 합격·비교 기준 지정으로 자동 처리하지 않는다.
