# 관심 공고함: 캘린더와 필터 구현

## 이번 범위

- 회원용 `/app/saved-programs`에서 기존 WorkspaceLayout과 사이드바를 재사용합니다.
- [아임웹 캘린더 참고](https://imweb.me/qna?mode=faq&q=71554)의 얇은 격자와 간결한 이동 버튼을 GovBiz 색상으로 구성했습니다.
- 이전/다음 연도, 이전/다음 월, 연도·월 직접 선택을 제공합니다. 선택 범위는 2000~2100년이며 오늘 날짜는 달력에서 강조합니다.
- `공고 찾기` 버튼은 두지 않습니다.
- 공고명·기관명, 지역, 지원 분야, 지원 대상, 마감 공고 제외 조건을 즉시 적용합니다.
- 적용 조건은 칩으로 확인·개별 해제할 수 있고 전체 초기화와 필터 전후 건수를 제공합니다.
- 공고가 많으면 해당 주의 높이가 늘어나고 달력 내부에서 스크롤합니다. 요일은 고정되며 제목은 줄바꿈합니다.
- 접수 시작일에는 `시`, 마감일에는 `끝` 배지를 표시합니다. 시작일과 마감일이 같으면 `당일` 일정 하나로 합칩니다.
- 좁은 화면에서는 달력에만 가로 스크롤을 허용합니다.
- 월 이동은 내부 스크롤을 초기화합니다. 화면을 처음 열면 오늘이 있는 주를 확인할 수 있습니다.

## 데이터와 구조

현재는 화면 진입 시 서울 기준 현재 월에 생성하는 예시 공고 24건입니다. 각 공고의 시작일과 마감일을 날짜별 일정으로 변환하며, 월을 바꿔도 예시 공고 날짜를 다른 달로 바꾸지 않습니다. 해당 월에 데이터가 없으면 빈 상태를 표시합니다.

`SavedProgramsPage(View) → useSavedProgramCalendarViewModel(달력·필터 화면 상태) → savedProgramCalendar(필터 규칙·날짜 배치·예시 데이터)`

네트워크·영속성 작업이 없는 UI 단계이므로 가짜 UseCase나 Repository를 추가하지 않았습니다. 실제 저장 연동 단계에서 프로젝트의 UseCase와 Repository 경계를 따릅니다. 기존 Redux·공통 Hook·인증 동작은 수정하지 않았으며, 공통 파일에는 화면 진입에 필요한 경로·라우트·메뉴만 추가했습니다.

## 제외한 범위

관심 등록·해제 및 실제 데이터 적재, 공고 상세/뒤로가기, 상시 접수 목록, 지원사업 관리/파이프라인, AI 기능은 이번 변경에 포함하지 않습니다. 이 시안을 실제 관심 저장 기능이 완성된 것으로 취급하면 안 됩니다.

## 검증

- 날짜 배치: 윤년, 6주인 달, 연도 경계, 날짜 없는 공고 제외, 시작·마감·당일 변환, 동일 날짜 공고 200건 보존.
- 화면: 공통 헤더·필터 적용/해제/초기화·마감 제외·이동 버튼·직접 선택·오늘 날짜 강조·빈 달·회원 라우트와 비회원 접근 제한.
- 브라우저: 회원 세션 API를 가로챈 예시 환경에서 1440×900, 1024×800, 375×812 확인. 데스크톱 외부 스크롤 방지, 내부 스크롤, 좁은 화면의 문서 가로 넘침 방지 확인. 실제 DB 저장 검증은 아닙니다.
- 전체 Vitest 75파일/935테스트 통과. Oxlint, TypeScript 및 Vite 빌드 통과. Vite 번들 크기 경고는 남아 있습니다.
- 로컬 pnpm 11.19.0과 프로젝트 요구 11.22.x가 달라 `pnpm test/lint/build`는 실행 진입에 실패했습니다. 의존성이나 잠금 파일을 바꾸지 않고 설치된 Vitest·Oxlint·TypeScript·Vite를 Node 24로 직접 실행했습니다. 지정 pnpm 환경에서의 재검증은 남아 있습니다.

다음 작업은 사용자 확인 후 관심 등록·실제 데이터 적재를 별도 범위로 진행합니다.
