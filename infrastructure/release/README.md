# MSA 이미지 발행

이전 `GovBiz-Team/GovBiz`의 네 서비스 GHCR 발행 도구를 보존한 디렉터리입니다.
**통합 교육기관 저장소에서는 자동·수동 발행 모두 migration lock으로 중지되어 있습니다.**
기존 별도 저장소의 설정이나 실행 중인 Mac 클러스터를 변경한 것은 아닙니다.
개인 fork용 저장소·브랜치·패키지 검증을 연결하기 전에는 변수를 켜거나 이 도구를 직접 실행하지 않습니다.
기존 EC2/SSM 배포와 분리하며 Kubernetes에 직접 접속하지 않습니다. 범위·검증·권한 설명은
[이미지 릴리스 안내](../../docs/msa-image-release.md)를 참고하세요.
