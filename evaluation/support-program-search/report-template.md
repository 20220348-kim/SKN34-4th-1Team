# 지원사업 검색 실데이터 평가 보고서

> 실행 환경과 원본 파일 식별값은 [실행 기록](run-manifest.example.md)에 기록한다. 이 문서는
> 실제 평가마다 복사해 결과를 작성하며, 예시 값으로 채우지 않는다.

## 평가 범위

- runId:
- 기준 시각(KST):
- `referenceDate` (fixture/capture 동일):
- 공고 제공처:
- 전체 공개 공고 수 / 평가 대상 OPEN 공고 수:
- dev / heldout 질문 수:
- 답변 가능 / 무결과 / 판단 보류 질문 수:
- 질문 유형: 분야·목적 / 대상 / 지역 / 복합 조건 / 무관 질의

## 대표 결과

대표 수치는 튜닝에 사용하지 않은 `heldout` 결과로 작성한다. `null`은 0점이 아니라 라벨 또는
표본이 부족해 측정할 수 없다는 뜻이다.

| 단계 | 지표 | heldout 결과 | 해석 |
| --- | --- | --- | --- |
| 후보 검색 | macroRecallAt20 |  | 관련 공고가 후보 20개 안에 들어오는지 |
| 후보 검색 | noMatchFalsePositiveRate |  | 무관 질의에도 후보를 반환하는지 |
| 최종 추천 | macroRecallAt5 |  | 관련 공고가 최종 5개 안에 들어오는지 |
| 최종 추천 | mrrAt5 |  | 첫 관련 공고가 앞에 배치되는지 |
| 최종 추천 | noMatchFalsePositiveRate |  | 무관 질의에도 최종 추천을 반환하는지 |

`dev` 결과는 진단용으로만 아래에 별도 기록한다. heldout 결과를 보고 검색 설정·프롬프트·임계값을
바꾸지 않는다.

| 단계 | 지표 | dev 결과 |
| --- | --- | --- |
| 후보 검색 | macroRecallAt20 |  |
| 후보 검색 | noMatchFalsePositiveRate |  |
| 최종 추천 | macroRecallAt5 |  |
| 최종 추천 | mrrAt5 |  |
| 최종 추천 | noMatchFalsePositiveRate |  |

| 유형 | 질문 ID | 질문 | 관련/반환 공고 ID | 관찰 내용 |
| --- | --- | --- | --- | --- |
| 후보 누락 |  |  |  | 관련 공고가 후보 20개에 없음 |
| 최종 탈락 |  |  |  | 후보에는 있으나 최종 5개에서 빠짐 |
| 무관 질의 오추천 |  |  |  | 정답 없음인데 결과가 반환됨 |
| 판단 보류 |  |  |  | 문서만으로 관련성을 확정할 수 없음 |
