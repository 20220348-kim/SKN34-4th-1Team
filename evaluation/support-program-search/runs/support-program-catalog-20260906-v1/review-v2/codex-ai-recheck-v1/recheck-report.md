# 미확정 42건 추가 AI 검토 결과

## 결론

기존 미확정 42건에 대해 Luna 작업 5개가 한 차례 추가 독립 판정을 수행했다. 추가 판정 210개를 수집해
24건은 합의했고 18건은 미확정으로 남겼다. **3단계의 참조 판정을 보완한 상태이며 실제 검색 품질 측정은 아직 없다.**

| 항목 | 최초 판정 | 추가 검토 반영 후 |
| --- | ---: | ---: |
| 질문·공고 조합 | 321 | 321 |
| 합의한 조합 | 279 | 303 |
| relevant | 19 | 25 |
| irrelevant | 260 | 278 |
| 미확정 | 42 | 18 |
| 전체 행이 확정돼 평가에 사용할 수 있는 질문 | 4 / 16 | 8 / 16 |
| 위 질문 중 관련 공고가 있는 질문 | 1 | 4 |
| 실제 검색 캡처 / Recall / MRR | 없음 | 없음 |

새로운 관련성 합의 6건·부적합 합의 18건이 추가됐다. 합의 건수가 늘었다고 판정 정확도나 검색 정확도가
그만큼 개선됐다고 해석할 수 없다. 최초 합의 279건은 재심사하지 않았고 같은 모델의 공통 오류도 남을 수 있다.

## 범위와 출처

- 스냅샷: 기준일 `2026-09-06`, 고정 공고 1,422건. 질문 16개와 dev/heldout 구분은 그대로다.
- 최초 실행: `../codex-ai-v1/ai-review.json`, 1,605개 판정. 원본을 수정하지 않았다.
- 추가 실행: `judge-1.jsonl`~`judge-5.jsonl`, 각각 42개 판정. 실제 작업 ID는 `assignments.json`에 기록했다.
- 모델: `gpt-5.6-luna`. 프로젝트 OpenAI API 키·웹 검색·실제 운영 검색은 사용하지 않았다.
- 정책: 최초 rubric·judge별 instruction·4/5 합의 기준 유지. 3:2 또는 정보 부족은 미확정이다.
- 추가 판정 전 [검토 계획](review-plan.md)을 고정했고, 새 judge에게 기존 표결·다른 judge의 답·검색 점수를 제공하지 않았다.
- 대상 42건은 새 다섯 표로 교체했다. 기존 표를 섞어 10표로 계산하거나 유리한 표만 택하지 않았다.
- 일부 근거 인용은 원문과 정확히 일치하지 않아 해당 judge가 인용만 교정했다. 판정·이유는 바꾸지 않았다.
- [원인 감사](cause-audit.json)는 독립 표결 완료 후 Luna가 작성하고 주 에이전트가 기존 이유·원문과 대조해
  보완한 AI 분석이다. `sourceCrosscheck`에 보완 출처를 남겼다. 사람 검증도, 최종 판정을 결정하는 별도 표도 아니다.
- 이번 추가 검토는 한 번으로 종료한다. 합의될 때까지 반복하거나 미확정을 부적합으로 바꾸지 않는다.

## 확인한 오류와 정보 부족의 예

1. **결정과 이유의 모순:** Q05 / `BIZINFO:PBLN_000000000126120`의 기존 judge-4·5는
   특허분쟁 대응이 견본품 배송비와 다르다고 이유에 쓰면서 `relevant`로 표시했다.
2. **명시된 원문 오독:** Q08 / `BIZINFO:PBLN_000000000116004`의 기존 judge-4는 수준확인서 지원이
   명시되지 않았다고 썼다. 고정 본문에는 수준확인서·진단보고서 제공이 있다.
3. **질문의 일부만 일치:** Q04는 계약서 번역과 국내 바이어 통역을 함께 요구한다. 통역만 있는 공고에서
   두 조건을 모두 요구할지 일부 일치를 인정할지 판정이 갈렸다. 고정 정책은 두 조건을 모두 검사한다.
4. **정보 부족:** Q03의 일부 공고에는 시험분석은 있어도 유해물질 분석 수수료나 대상 시·군이 구체적으로
   없다. Q13의 일반 홍보·마케팅이라는 표현만으로 온라인 광고비가 지원된다고 추정하지 않는다.

원인 분류는 AI의 해석이며 각 판정자의 내부 판단 과정을 알아낸 사실이 아니다. 개별 이유가 일반적인 문구뿐이면
정확한 오류 원인은 알 수 없다고 기록한다. 새 판정도 별도의 사람 검증을 거치지 않았다.
