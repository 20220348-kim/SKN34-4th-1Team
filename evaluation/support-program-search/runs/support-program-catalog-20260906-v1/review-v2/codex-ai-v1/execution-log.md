# Codex Luna 독립 판정 실행 기록

- 선택 모드: AI-only. 실제 사람 판정은 AI 합의 정답에 사용하지 않는다.
- 사용자 요청: 프로젝트 OpenAI API 키를 쓰지 않고 Codex의 Luna 하위 에이전트 사용.
- 실제 생성 모델: 다섯 실행 모두 `gpt-5.6-luna`, reasoning effort `medium`.
- 실행 식별자: `assignments.json`에 실제 생성한 Codex 작업 ID를 기록했다.
- 격리: 각 작업은 대화 이력 없는 `fork_turns=none`으로 생성했다. 공통 고정 입력·정책과 해당 judge 지시만 전달했다.
- 각 작업은 다른 작업의 답, 기존 사람 판정, 검색 순위 및 예상 정답을 열지 않도록 지시했다.
- 작업은 작은 입력 묶음으로 이어서 수행하며 동일 judge의 작업 ID를 유지한다.
- 입력: 321개 질문/공고 조합. 5회씩 총 1,605개 개별 판정이 필요하다.
- 판정 원본: 각 `judge-N.jsonl`. 수집 후 `ai-review.json`에 출처와 검증된 근거를 보관한다.
- API 키 접근 및 프로젝트 API 호출: 없음. Codex 작업 사용량은 발생한다. 개별 판정별 API 토큰 수는 알 수 없어 null이다.

## 초안 검증

첫 judge-1 실행이 미처리 299개 항목을 동일한 판단 보류 문구로 채우고 긴 본문을 근거로 반환했다.
이 초안은 실제 완료된 판정으로 채택하지 않았으며 `judge-1-rejected-draft.jsonl`에 별도 보존했다.
같은 독립 작업에 처리 범위를 작은 묶음으로 나누어 다시 판정하도록 요청했다.

원문에 없는 생략 부호·의역이 evidence에 들어간 항목은 정확한 원문 인용이 아니므로 수집하지 않는다.
해당 judge가 자신의 입력을 다시 확인해 고치며, 다른 judge의 판정을 전달하거나 정답 방향을 지시하지 않는다.
이 기록은 AI 참조 정답 생성 과정이지 사람 검토 또는 실제 검색 성능 검증 결과가 아니다.

수집 검증에서 judge-3의 Q02/126026, Q04/126103에 같은 인용이 두 번 들어간 것을 발견했다.
부모 작업이 중복된 두 번째 인용만 기계적으로 제거했다. 판정·사유·첫 번째 원문 인용은 변경하지 않았다.

## 결과 상태

최종 5개 파일 1,605개 판정의 모든 조합·근거·내용 해시 검증 통과. `ai-review.json` 수집 완료.
AI-only 선택 결과는 합의 279개(추천 가능 19/불가 260), 미확정 42개다.
미확정 항목이 있는 질문 전체를 제외하면 평가 가능 질문은 4/16개다. 실제 검색 캡처·Recall/MRR은 아직 없다.
전체 결과 및 재사용 안내는 `labeling-report.md`에 기록했다. 다른 판정을 예약하거나 API 호출을 실행하지 않는다.
