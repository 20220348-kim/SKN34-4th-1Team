# Luna AI-only 판정 결과

**AI 참조 판정 생성은 완료했다. 실제 검색 품질 평가는 아직 완료하지 않았다.**

## 이번에 완료한 것

- 질문 16개, 고정 공고 1,422건에서 구성한 검토 풀 321개 질문/공고 조합.
- Codex `gpt-5.6-luna`의 독립 실행 5개로 총 1,605개 개별 판정 완료.
- 기존 사람 판정·검색 순위·다른 judge의 답을 입력으로 공유하지 않았다.
- 프로젝트 OpenAI API 키 접근·호출 없음. Codex 작업 사용량은 발생하며 개별 API 토큰 수는 알 수 없어 `null`.
- 원문 인용 일치·입력 해시·정책·복합 식별자·중복/누락·실행 배정 검증 통과.
- AI-only / 혼합 / 사람 방식 선택 도구와 각 모드의 파일을 준비했다.
- 기존 사람이 대화에서 내린 판정 2건은 별도로 보존했다. AI-only 정답에는 사용하지 않았다.

## AI-only 합의 결과

모든 5개 판정이 있고 4개 이상이 동일하게 추천 가능/불가로 판정한 경우만 채택했다.
3:2 분할이나 정보 부족 등은 미확정으로 유지했다. 이 기준은 점수를 본 뒤 바꾸지 않았다.

- 추천 가능 합의: **19개**
- 추천 불가 합의: **260개**
- 미확정: **42개**
- 합의한 조합 합계: **279 / 321개**. 이 비율은 검색 정확도나 판정의 정답 확률이 아니다.

미확정 공고 한 건만 부적합으로 간주하거나 빼면 Recall의 정답 분모가 달라지므로, 해당 질문 전체를 제외한다.
따라서 현재 사용할 수 있는 질문은 **Q01·Q09·Q15·Q16의 4 / 16개**다. 이 중 관련 공고가 있는 질문은
Q01 하나뿐이다. heldout에서 남는 Q15·Q16은 모두 무결과 질문이라 양성 질문의 Recall/MRR을 평가할 수 없다.
이는 최초 계획의 12~20개 대표 질문 평가 완료 기준을 충족하지 못한다.

실제 검색 후보·최종 추천을 실행한 `capture.json`도 아직 없다. **현재 실제 Recall·MRR 점수는 없으며,
검색이 전반적으로 잘된다는 결론을 내리지 않는다.** 풀 밖의 누락 관련 공고도 전수 판정한 것이 아니다.

검토 화면은 [공유 안내](../../README.md#2-엑셀-없이-화면-열기)에 따라 로컬에서 생성한다. 원본 판정은 다시 실행하지 않는다.

혼합 모드의 79건은 미확정 42건과 질문별 합의 표본 37건이다. 기존 사람 판정 2건은 별도 유지하지만 이번
필수 표본에 포함되지 않아 필수 대기 수에서 차감되지 않았다. 불일치가 많으면 혼합 모드도 몇 건만으로 끝나지 않는다.
지금은 사용자 선택대로 AI-only 결과를 사용하며 사람에게 검토를 요구하지 않는다.

## 보관과 다음 작업

같은 공고·질문·판정 정책은 지금의 파일을 재사용한다. 매일 다시 판정할 필요가 없다. 검색 방식·프롬프트·모델·
제공처를 크게 바꾸거나 오추천을 고칠 때만 같은 기준으로 전후를 비교한다. 공고/질문 내용이 바뀌면 영향을 받는
판정은 새 버전으로 다시 만든다. 이 실행의 고정 입력·원본 판정·선택 결과·보고서는 Git 포함 대상이며,
새 실행과 생성 HTML·엑셀·임시 출력은 기본적으로 제외한다. [공유 안내](../../README.md)에 따라 다른 PC에서 이어받는다.

시간을 아끼려면 지금은 판정 자료를 보관하고 다음 기능으로 넘어갈 수 있다. 다만 ‘실데이터 검색 품질 평가 완료’라고
발표하지는 않는다. 이후 실제 점수가 필요할 때는 **실제 검색 캡처 확보**와 **평가 가능한 질문 범위 보완**이 필요하다.
미확정 항목은 AI로 다시 검토할 수도 있지만, 같은 요약에 없는 사실을 AI가 만들어 채우거나 점수를 높이려고
사후에 합의 기준을 낮추지는 않는다. 이 보고서는 추가 판정이나 API 실행을 예약하지 않는다.
