# 실제 검색에서 추가된 249쌍의 독립 AI 판정

2026-09-06에 Codex가 실제 `gpt-5.6-luna` 하위 작업 5개로 수행했다. 실제 검색 캡처가 성공한 뒤,
기존 321쌍에 없던 249쌍만 대상으로 분리했다. 이는 사람 검토가 아니며 프로젝트 OpenAI API 키를 사용하지 않았다.

동시 실행 제한 때문에 처음 3개 작업을 시작하고, 빈 자리가 생긴 뒤 4·5번 작업을 시작했다.
각 작업은 대화 이력을 전달하지 않는 새 실행으로 생성했다. 정책의 해당 judge 지침·동일한 전체 blind input만
읽게 했으며, 다른 판정·과거 라벨·검색 순위·점수·프로젝트 키·외부 웹을 읽지 않도록 했다.
판정 내용을 서로 전달하지 않았고 root는 판정을 합의시키기 위한 수정이나 반복 투표를 요청하지 않았다.

- 입력 해시: `1e0bc16114657d8bd0298fcc69aa231d108c5ec77c98b735b64fa047e3788fc9`
- 정책 해시: `4fca4fbcd1382e706b6382e01a356263102229e154307bdf5e40025bb1d6cde7`
- 전체 1,245표, 누락 0. 판정 파일마다 헤더 1줄 + 249행이다.
- 기존 `run-ai-review.py collect`로 실제 작업 ID·모델·입력/정책 해시·쌍 집합·정확한 원문 인용을 검증했다.
- 검증된 원표: [ai-review.json](ai-review.json). 토큰 사용량은 관측하지 않았으므로 `usage: null`을 유지한다.
- 동일 정책의 4/5 합의로 신규 238쌍(관련 3 / 무관 235)을 확정하고 11쌍을 미확정으로 남겼다.
- 과거 미확정 18쌍을 합의로 바꾸지 않아 최종 풀의 미확정은 29쌍이다.

[transfer-plan.json](transfer-plan.json)은 고정 스냅샷·질문·설정·실제 캡처·기존 원표와 신규 쌍의 출처 해시를
고정한다. 사람 판정 원본은 보존하지만 AI-only 기준에 섞지 않는다. 같은 모델 5회 실행은 서로 다른 모델을
사용한 검증이 아니고, 원문 인용 검증은 판정 자체가 옳다는 증명이 아니다.
