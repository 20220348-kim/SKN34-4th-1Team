# 의미검색 본문 정리와 RRF k 비교 — 2026-10-15

채택 조합은 `semantic-focus-v1 + RRF k=1`이다. 동일 16개 질문의 양성 12개 평균에서 기존 RRF k=60 대비 Recall@20·Recall@5는 같고 MRR@5는 0.722222 → 0.854167로 올랐다. 다만 Q04의 첫 관련 공고는 3위 → 4위로 밀렸다. 새로운 독립 검증 질문은 0개이며, 이 결정은 기존 튜닝셋에서 결과를 본 뒤 내린 사후 선택이다. 운영 색인 교체나 배포 완료를 이 보고서로 주장하지 않는다.

## 고정 비교와 판정

기준일 2026-09-06의 공개 BIZINFO 공고 1,422개와 이전 16개 질문·질문 벡터를 재사용했다. 의미검색과 BM25에서 각각 상위 20개를 가져와 동일 가중치로 `Σ 1/(k+rank)`를 합산한다. 순위는 1부터 시작하며 production Kotlin Double과 같은 IEEE754 binary64 나눗셈·합산 순서를 사용한다. 부동소수점 점수가 같으면 BM25 순위, 공고 ID 순으로 정렬한다. 결과는 20개다. 이 보고서의 ‘기존 RRF’는 이전에 채택된 BM25 동점 처리 + k=60이며, 그보다 앞선 의미검색 우선 동점 기준과 혼동하지 않는다.

기존 828개 판정은 [이전 실행](../rrf-tuning-20261015-v1/README.md)에서 수정 없이 참조한다. 새 의미검색 top20에만 등장한 미판정 50쌍은 순위·방법을 숨긴 질문/공고 본문을 두 독립 AI 검토자가 각각 판정했다. 50쌍 모두 판정이 일치했고, irrelevant 45·unclear 5·relevant 0이었다. 의견이 다르면 unclear로 두는 규칙을 적용했다. 사람이 검토한 정답은 0개다. 총 878쌍은 relevant 47·irrelevant 801·unclear 30이다. 47은 질문-공고 관련 쌍의 수이며 전체 코퍼스의 완전한 정답 집합은 아니다.

Recall은 해당 질문의 확인된 관련 쌍을 분모로 하며, MRR@5는 상위 5개 내 첫 관련 공고 순위의 역수다. 양성 12개를 같은 비중으로 평균한다. 관련 판정이 없는 Q09·Q10·Q15·Q16은 평균에서 제외하고 별도 표시한다. 미판정 후보를 irrelevant로 처리하지 않으며, 최종 비교 후보 전체의 판정 누락 시 재생은 실패한다.

## 본문·실제 호출·Qdrant 확인

기존 본문은 `제목 → 기관 → 지원대상 → 분야 → 지역 → 신청기간 → 내용`, 새 본문은 `제목 → 지원대상 → 내용 → 분야 → 지역`이다. 공개 fixture의 라벨 있는 7줄을 이용해 다섯 필드를 손실 없이 재구성했으며 비어 있는 필드와 잘린 문서는 0개다. 기관·신청기간은 임베딩 본문에서 빠진다. inputs.json의 실험 schema는 당시 KSTARTUP 분류 제외 계획을 역사적으로 보존하지만, 평가 코퍼스의 KSTARTUP 공고는 0개다. 실제 production은 KSTARTUP 분류를 유지하며 그 품질은 이번 실험에서 측정하지 않았다.

`text-embedding-3-small`, 1,536차원으로 공개 문서 1,422개를 45회(32개×44회+14개) 처리했다. 실제 보고 입력 토큰은 521,698이며 기록 단가 $0.02/백만 토큰 기준 추정 비용은 $0.01043396이다. 승인 상한은 $0.03, 재시도 0회다. 기존 질문 벡터 16개를 재사용해 새 질문 임베딩·순위 모델 호출은 0회다. 이는 청구서 대조 결과가 아닌 사용량×기록 단가 계산이다.

로컬 Qdrant **1.17.1**에서 양쪽 문서를 같은 조건으로 다시 조회했다. 기존 Qdrant top20은 이전 저장 순위와 16/16 질문에서 순서까지 같았고, 새 Qdrant top20은 새 벡터의 float64 exact cosine top20과 16/16에서 순서까지 같았다. 따라서 이 top20 비교의 순위 차이를 ANN/계산 방식 차이로 설명할 필요는 없다. 이 확인이 다른 코퍼스·깊이·운영 환경의 일치까지 보장하지는 않는다.

RRF도 2본문×6k×16질문=192개 순위를 정확한 Fraction 합산과 production 방식으로 비교했다. 기존 k=5/Q08의 8·9위, 기존 k=10/Q15의 5·6위, 새 k=5/Q08의 7·8위에서 부동소수점 반올림으로 순서가 교환됐다. metrics.json의 순위는 production 방식에 맞췄으며, 모든 점 지표·unclear 범위·paired 범위는 동일함을 검증했다. 채택 새 k=1과 기준 기존 k=60은 각각 16/16에서 Fraction 순위와도 같다.

새 본문 실험 전의 원래 828판정 k 실험을 별도로 보존한다. 기존 본문에서 여섯 k의 Recall@20/Recall@5는 모두 0.747917/0.476389였다. MRR@5는 아래와 같다. 후속 판정 50개를 이 역사적 점수에 소급 반영하지 않는다.

기존 [입력](../rrf-tuning-20261015-v1/inputs.json), [828판정과 원천 추적](../rrf-tuning-20261015-v1/labels.json), [계산 helper](../rrf-tuning-20261015-v1/replay.py) 및 그 입력이 가리키는 공유 공개 fixture를 함께 보존해야 한다. 원문 코퍼스·벡터·환경변수·키·원시 API 응답은 이 폴더에 복제하지 않았다. work 원본 해시는 수집 출처를 추적하기 위한 것으로, 그 임시 파일 없이도 저장된 입력의 지표 재생은 가능하다.

구현 연결에 대한 로컬 선택 검증은 Core 102개·Catalog 31개·평가 도구 35개 테스트가 통과했다. 이 평가 묶음의 replay와 `git diff --check`도 통과했다. 전체 CI는 아직 실행하지 않았고 운영에는 배포하지 않았다. 새 벡터를 사전 준비하는 동안 동기화·공개는 동결하고, 기존 색인의 prune을 수행하지 않는다. 로컬 테스트 결과를 운영 재색인 완료나 새로운 독립 검색 품질 검증으로 해석하지 않는다.

같은 16질문에서 본문·동점·후보·가중치·k를 여러 차례 검토했으므로 선택 편향이 있다. 두 AI의 일치는 사람 검증을 대신하지 않는다. fresh holdout 0개, human review 0개이며, 미판정 코퍼스 전체의 누락이나 새 질문 성능은 이 범위에 포함되지 않는다.
