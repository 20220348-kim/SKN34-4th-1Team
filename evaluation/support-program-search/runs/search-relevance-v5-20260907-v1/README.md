# v5 대표 질문 첫 실행과 지원 목적 보완

2026-09-07, 사용자 승인 최대 12회 범위에서 실제 OpenAI 호출 11회를 사용한 개발 진단이다.
호출 수는 성공한 내부 경로 로그와 production의 `max_retries=0`, `max_turns=1`로 확인한 수이며,
이 첫 실행은 OpenAI token usage·청구액 원장을 수집하지 않았다.

- 모델: `gpt-5.6-luna`, reasoning `none`, 최대 출력 10,000 tokens.
- 질의 임베딩: `text-embedding-3-small`, 1,536차원.
- 실제 DB 1,506건, 검색 준비 상태 `SEARCHABLE`.
- 자동 동기화·색인을 비활성화한 채 현재 DB·Qdrant를 읽었다. 데이터를 초기화하지 않았다.
- 첫 질문 3개: 부산 제조업 수출 지원 / 대전 AI 기술개발 / 서울 SW 사업화 지원금.
- 대화 해석 3회, 질의 임베딩 3회, 랭킹 3회가 모두 성공했다.
- 해석과 검색을 분리해 검사하기 위해 검색에는 미리 고정한 요청을 사용했다. 해석 결과를 자동 확정한 UI 평가가 아니다.

## 확인한 문제와 같은 질문 재검증

서울 SW 사업화 지원금 질문은 사업화 의도를 유지했지만, 첫 추천에 영화 로케이션·후반작업 공고가 섞였다.
확인된 업종과 요청 활동을 함께 평가하고, 돈을 준다는 사실만으로 다른 활동의 지원을 관련 있다고 판단하지 않도록 보완했다.
같은 공개 입력으로 임베딩 1회·랭킹 1회를 추가 실행했다.

| 항목 | 보완 전 | 보완 후 |
|---|---:|---:|
| 검색 HTTP 상태 | 200 | 200 |
| 응답 시간 | 24.566초 | 28.284초 |
| 반환 공고 | 4개 | 2개 |
| 로케이션·영화 후반작업 공고 | 2개 | 0개 |

남은 공고는 모두의 창업 프로젝트와 대구 혁신클러스터 사업이다. 모두 자격 `REVIEW_REQUIRED`이며,
대구 사업은 사업장·이전 예정과 특화산업 확인이 필요하다. 또한 해당 API 본문에서 지원금 지급은 명확하지 않다.
이 잔여 문제 때문에 후속 정밀도 실험을 별도 실행한다. 4개를 2개로 줄였다는 사실만으로 품질 합격을 선언하지 않는다.

## 기록과 제한

- `seoul-before.json`, `seoul-after.json`: 완전하게 보존된 같은 요청의 실제 응답.
- `before-prompt.txt`, `after-prompt.txt`: 각 실행 시 배포돼 있던 전체 랭킹 프롬프트(회사 조건 지침 포함).
- `comparison.json`: 입력 동일성, 개수·점수·인용 계약 검사와 관찰한 제외 결과.
- `initial-capture.json`: 첫 실행의 **부분 기록**이다. 터미널 출력 상한으로 부산 검색과 대전 해석·검색의
  전체 응답이 유실됐다. 잘린 JSON을 정상 응답으로 복구하거나 평가에 쓰지 않았다. 성공 경로 로그만 확인 가능하다.

정답 라벨, 모든 후보의 원점수, 고정 후보 집합, 반복 측정이 없는 소수 개발 진단이다.
Recall·MRR·전체 정밀도·통계적 우월성으로 해석하지 않는다. 출력 유실 때문에 유료 요청을 재호출하지 않았다.
다음 고정 후보 실험은 응답과 API 사용량을 실행 파일로 즉시 보존한다.
