# Claude 대리 검증 — 마침표 날짜 반영 뒤 (`claude-proxy-sonnet-v2`)

설립일 근거에 한글 맞춤법 문장 부호 규정의 숫자 날짜(`2021.3.15`, `2021. 3. 15.`)를 받도록 프롬프트·검증기·기대 라벨
(S033, M07 2·3턴)을 바꾼 뒤 같은 방법으로 다시 답한 실행이다. **OpenAI 운영 모델(`gpt-6-luna`)의 측정이 아니며**,
기대 라벨도 AI가 작성한 기대 동작이라 사람이 검토한 정답이 아니다.

## 실행 방법

- 실행일: 2026-10-11. 입력: `proxy/` 264줄(`inputs-manifest.json`의 지문과 일치), 유료 API 호출 0회.
- 대리 모델: Claude Sonnet 에이전트 4개가 66줄씩 나눠 줄마다 한 번 답했다. 라벨 수정으로 입력이 바뀐 M07 3턴 한 줄은
  새 에이전트가 같은 조건으로 다시 답했다.
- 블라인드: 에이전트는 기대 라벨이 없는 별도 폴더(시스템 지침·응답 형식·자기 몫 입력)만 읽었다.
- 채점: `replay.py --run claude-proxy-sonnet-v2`(`report.md`·`metrics.json`·`ai-responses.jsonl`).

## 결과와 비교

같은 라벨·검증 코드로 채점한 값이다. 이전 실행은 출력만 가져와 현재 기준으로 다시 채점했다(입력 지문은 이전 프롬프트).

| 실행 | 상태 정확도 | 문항 통과율 | 필드 F1 | 검증 거부 |
|---|---:|---:|---:|---:|
| `claude-proxy-sonnet-v1`(이전 프롬프트, Sonnet) | 98.9% | 87.9% | 96.9% | 0 |
| `claude-proxy-sonnet-v2`(이번, Sonnet) | 99.6% | 92.0% | 98.3% | 0 |
| `claude-proxy-v1`(이전 프롬프트, Haiku) | 90.5% | 73.5% | 87.9% | 5 (이전 검증기 7) |

- 이번 변경으로 설명되는 차이는 마침표 날짜 두 턴(S033, M07 2턴)이다. 업력 범주 16문항은 모두 통과했고 필드 F1은 1.0이다.
- 결과 참조(N번·비교) 문항 등 나머지 차이는 같은 지침에서도 실행마다 달라지는 답의 차이다. 구조 개선으로 해석하지 않는다.
- Haiku 출력의 거부 7건 중 `2021.3.15` 등 2건은 새 검증 규칙에서 받아들여진다. `21년`·`이천이십일년`을 연도로 둔 답은
  여전히 거부되며, 프롬프트에 이런 표현은 묻도록 한 문장을 더했다(Haiku로 다시 답하지는 않았다).
- 남은 실패 21건 중 14건은 결과 참조(현재 스키마에 턴 종류 없음)다.
