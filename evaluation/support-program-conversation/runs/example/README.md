# 예시 출력 (측정 결과 아님)

`outputs.jsonl`은 재생 도구와 Core 재생 테스트를 위한 **손 작성 출력 3건**이다. 모델이 만든 출력이 아니며
OpenAI·Claude 대리 검증 결과도 아니다. 나머지 문항은 일부러 비워 두었으므로 이 폴더로 만든 보고서의 수치는
의미가 없다.

| 문항 | 출력 | 재생 결과 |
|---|---|---|
| `S002#1` 서울 AI 창업지원(등록 소재지 서울특별시) | 검색 의도 + 표기만 다른 지역 `서울` | 200, 통과(지역은 변경 아님) |
| `S032#1` 21년 설립이에요 | 메시지에 없는 `2021년` 인용 | 503, AI Service 검증 거부 |
| `M14#1` 부산이나 대구 쪽 수출 지원 | 지역 확인 질문 + 수출 지원 초안 | 200, 통과 |

재생 결과는 `backend/core-service/src/test/resources/support-program-conversation/example-ai-responses.json`의 원본이다.
