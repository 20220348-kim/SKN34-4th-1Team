# Claude 대리 검증 기준선 (`claude-proxy-v1`)

현재 조건 해석 프롬프트·스키마에 OpenAI 운영 모델 대신 **Claude가 답한 출력**을 재생·채점한 기준선이다.
**OpenAI 운영 모델(`gpt-6-luna`)의 측정이 아니며**, 기대 라벨도 AI가 작성한 기대 동작이라 사람이 검토한 정답이 아니다.
해석 스키마 v2(공고 지역 분리·마감 기간·상대 업력·대상 유형·턴 종류 등)를 넣은 뒤 같은 방법으로 다시 실행해 전후를 비교한다.

## 실행 방법

- 실행일: 2026-10-08. 입력: `proxy/` 264줄(`inputs-manifest.json`의 지문과 일치), 유료 API 호출 0회.
- 대리 모델: Claude Haiku 4.5 에이전트 4개가 66줄씩 나눠 답했다. 운영 설정(추론 노력 `none`, 한 번 호출)에 맞춰 줄마다
  한 번만 답하고 고쳐 쓰지 않게 했다.
- 블라인드: 에이전트는 기대 라벨이 없는 별도 폴더(시스템 지침·응답 형식·자기 몫 입력)만 읽었다. `cases.json`과 채점 코드는 열지 않았다.
- 채점: `replay.py --run claude-proxy-v1`로 실제 AI Service HTTP 검증 경로를 거쳐 채점했다(`report.md`·`metrics.json`·`ai-responses.jsonl`).

## 결과 요약

| 지표 | 값 |
|---|---:|
| 상태 정확도 | 89.8% |
| 문항 통과율(상태·종류·필드·금지 규칙 모두) | 72.7% |
| 필드 F1 | 87.5% |
| AI Service 검증 거부(503) | 7건 (2.6%) |
| 잘못된 변경(금지 규칙 위반) | 3건 |

약한 곳은 설계 문서의 진단과 같다.

- 결과 참조·비교·더 보기: 현재 스키마에 턴 종류가 없어 `OUT_OF_SCOPE`로 답한다(결과 참조 통과 33.3%).
- 대상·청년(통과 50.0%): 대상 유형을 담을 칸이 없어 검색어에서 빠진다.
- 업력 날짜(통과 68.8%): "21년 설립", "2021.3.15", "이천이십일년" 같은 표현은 검증기가 거부해 해석 전체가 503이 된다.
- 공고 지역: "부산에서 하는 수출 지원"을 회사 소재지 변경으로 제안한다(소재지 보호 위반 2건).

## 한계

- Haiku는 운영 모델과 다른 모델이라 수치는 경향을 보는 용도다. 운영 모델 측정은 사용자가 승인한 예산으로 따로 한다.
- 한 에이전트가 66줄을 이어서 답해 줄 사이가 완전히 독립된 호출은 아니다.
- 여러 턴 시나리오는 이전 턴의 기대 상태를 입력으로 쓰는 턴 단위 채점이라 앞 턴 오류가 번지는 영향은 재지 않는다.
