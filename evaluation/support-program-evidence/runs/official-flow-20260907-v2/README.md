# 5단계 대상 조건 요약 보완 — 실제 검증 결과

[평가 안내](../../README.md) · [변경 전 공식 실행](../official-flow-20260907-v1/README.md)

## 결론

**승인된 추가 20회를 사용해 새 가상 질문 6개와 공식 공고 질문 6개의 검증을 마쳤습니다.**
12개 답변 모두 정상 반환됐고 기대 상태가 일치했습니다. 별도 AI 의미 검토에서도 12건 모두 일치로 판단했습니다.
공식 H01은 이전에 빠졌던 ‘중소·중견 제조기업’을 이번 답변에 포함했고, 기존 나머지 5건에서 새로운 오류는
확인하지 못했습니다. 따라서 5단계 HTML 기반 최소 범위와 이번 대상 조건 요약 보완의 실측을 마무리합니다.

이는 한 번씩 실행한 소규모 AI-only 관찰입니다. 전체 정확도 100%, 통계적으로 입증된 개선, 신청 자격
자동판정 완료 또는 PDF·첨부파일 지원을 의미하지 않습니다. 기존 실패·부분 일치 기록은 그대로 보존했습니다.

## 변경 및 고정 조건

수집·검색 결과에 있었던 대상 범위를 모델이 요약에서 생략해, 답변 프롬프트에 다음 지침만 보완했습니다.

- 질문과 관련된 규모·업종·지역·자격·제외/예외를 간결함 때문에 생략하지 않기
- 필수·우대·선택 조건과 원문의 AND/OR 관계 보존, 없는 제한 추가 금지
- 서로 다른 청크의 조건을 사용하면 해당 청크들을 함께 인용

모델·타임아웃·청킹·검색·HTTP 계약·인용 ID 복원·오류 처리·SDK 재시도 설정은 변경하지 않았습니다.
실제 흐름은 **HTTP API → Service → Agent → OpenAI → 인용 ID 복원 → Response**입니다.

| 조건 | 값 |
|---|---|
| 답변 모델 | `gpt-5.6-luna` |
| 모델 / Agent 타임아웃 | 25초 / 30초 |
| 임베딩 | `text-embedding-3-small`, 1,536차원 |
| Qdrant / MySQL | 임시 빈 Qdrant `v1.17.1` / Testcontainers MySQL 8.4 |

| 변경 후 프롬프트 SHA-256 | `560ad134d3ce657561e6dfa67793078c7526c5b5f1ebb691e6e972b27924655c` |
| 가상 fixture SHA-256 | `7cc1224e143f772e80713f267ed9b3b6d0262cabe75383b64f3e6b77ad496f8b` |

공식 v1/v2의 질문·저장 원문·원문 해시·Core→AI 요청은 동일합니다. 임베딩 요청 8개의 해시도 같습니다.
다만 프롬프트 외에 실행 시각·외부 서비스 상태·모델 비결정성이 달라질 수 있어 인과적 개선 증명은 아닙니다.
가상 6건은 이번이 첫 실행이므로 변경 전후 비교 자료가 아닙니다.

## 호출 및 토큰 사용량

| 실행 | 답변 호출 | 임베딩 호출 | 답변 입력 토큰 | 답변 출력 토큰 | 임베딩 토큰 |
|---|---:|---:|---:|---:|---:|
| 새 가상 질문 6개 | 6 | 0 | 6,816 | 719 | 0 |
| 공식 질문 6개 | 6 | 8 | 7,446 | 494 | 1,418 |
| 이번 합계 | 12 | 8 | 14,262 | 1,213 | 1,418 |

총 **20회**, 오류·자동 재시도 0회입니다. 답변과 임베딩은 과금 단가가 다르므로 토큰 합계를 비용으로
표현하지 않습니다. 공식 경로의 임베딩은 문서 2회·질문 6회이며, Core→AI HTTP는 18회입니다.

공식 질문 6개의 답변 사용량은 v1 대비 입력 **6,252→7,446**, 출력 **407→494**로 늘었습니다.
누락 보완을 관찰했지만 프롬프트와 답변이 길어지는 비용도 함께 기록합니다. 지연 원본은 캡처에 보존하며
한 번의 순차 실행으로 응답시간 개선을 주장하지 않습니다.
실행 종료 후 평가용 AI 서버와 이번에 만든 Qdrant를 종료했습니다. 임시 벡터만 제거했고 운영 DB나 기존
벡터는 사용·변경하지 않았습니다. API 키·인증 헤더·DB 비밀번호는 캡처에 포함하지 않았습니다.

## 답변 의미 검토 — AI-only

주 에이전트와 별도 검수 에이전트가 원문·답변·참조 사실·금지 주장을 대조했습니다. 이는 사람 검토나
서로 독립인 통계적 판정이 아닙니다. 자동 지표 `semanticFaithfulness`는 계속 `null`입니다.

| 사례 | 판정 | 원문 대조 결과 |
|---|---|---|
| TC01 | 일치 | 대전 본점·식품 제조업·소기업은 모두 필수, A/B 유형은 하나 이상으로 구분 |
| TC02 | 일치 | 없는 설립 연수·근로자 수 기준을 확인 불가로 안내, 제한이 전혀 없다고 단정하지 않음 |
| TC03 | 일치 | 공통 대상·휴/폐업·체납 제외와 유효한 징수유예의 한정된 예외 보존 |
| TC04 | 일치 | 징수유예가 있어도 휴업 제외는 면제되지 않음을 설명 |
| TC05 | 일치 | 지역·업종·규모 필수 조건과 고용 실적 가점을 구분 |
| TC06 | 일치 | 미수집 별첨의 제출 서류를 만들어내지 않음 |
| H01 | 부분 일치 → 일치 | 기존 대상 설명을 유지하면서 ‘중소·중견 제조기업’ 범위 보완 |
| H02 | 일치 → 일치 | 없는 제출서류를 추정하지 않고 원문에 있는 첨부 통합공고문 확인을 안내 |
| H03 | 일치 → 일치 | 비용 전액지원과 정확한 금액 미기재를 구분 |
| H04 | 일치 → 일치 | 강원 글로벌 IP 스타기업·해당 지위·해외 출원 중 OA·일부 비용 지원 보존 |
| H05 | 일치 → 일치 | 서류 목록은 확인 불가, 원문의 온라인 접수·문의기관 안내 |
| H06 | 일치 → 일치 | 없는 상한·기업 부담률을 제시하지 않음 |

H01은 추가 범위를 원문의 지원 목적 문장으로 보존했습니다. 원문의 불릿 관계는 여전히 명시적이지 않지만,
이번 답변은 ‘세 조건 모두 필수’나 ‘하나만 해당하면 충분’이라고 새로 확정하지 않았습니다.
원문 전체를 대조한 정성 판정이며, 해당 문구가 없던 기존 참조 JSON을 평가 후 수정하지 않았습니다.

TC01은 설립·근로자 기준 미기재와 출시일 기준 설명을 실제로 덧붙였으므로 청크 2의 추가 인용도 근거가
있습니다. TC02는 질문한 두 기준을 확인할 수 없다고 답했으므로, 질문과 무관한 참조 문장을 모두 나열하지
않았다는 이유로 감점하지 않았습니다. TC03의 ‘국세·지방세’ 병렬 표기는 ‘또는’를 명시하면 더 분명하나,
두 세금을 모두 체납해야 한다고 주장한 것은 아니어서 관계 왜곡으로 판정하지 않았습니다.

## 해석 한계

- 공식 경로는 고정 HTML 조각 재생이며 현재 사이트를 다시 다운로드하는 검증이 아닙니다.
- 공식 공고는 각각 청크 1개입니다. 가상 답변의 다중 청크 인용은 확인했지만 실제 다중 청크 검색 품질은 미평가입니다.
- 질문은 이미 관측한 실패에서 만든 회귀 자료입니다. 숨겨 둔 정답이나 대표적인 전체 사용자 분포가 아닙니다.
- API 요청은 본문 대신 해시만 남기므로 원문 요청 자체의 재해시나 외부 호출의 독립적인 암호학적 증명은 할 수 없습니다.
- 라이브 Core→AI 읽기 제한은 60초로 production과 다릅니다. 운영 지연·부하 검증으로 취급하지 않습니다.
- PDF·첨부파일·다른 제공처·새 HTML 형식·복잡한 공격·운영 배포는 이번 범위가 아닙니다.

이번 범위에서는 추가 호출 없이 마무리합니다. 같은 질문을 성공할 때까지 반복하거나 결과에 맞춰 정답을
바꾸지 않았습니다. 후속 확장은 별도 제품 범위를 정한 뒤 진행합니다.
